# MySpace-inspired page for Krisandy's bday

Live at https://kr.eerieieer.art

### What's on the page
- **Profile page:** photo, details table, mail box, contact links, friend space, media grid (2x3 / 3x3 images)
- **Blog:** entry list on the main page, one page per entry with images and a comments section
- **Message popup:** bottom-right chat window with minimize and close buttons, resizable chat area, image bubbles
- **Music player:** draggable player with play/pause, seekable progress bar, volume slider, scrolling song title

### Tech
This is a static client-side web app built on plain HTML, CSS and JavaScript with no framework and no build step :>   
Absolutely no backend #lolz (2)
